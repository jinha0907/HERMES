# HERMES

# 📘 프로젝트 개요
HERMES는 AI 기반 능동적 판단을 통해 정보취약계층인 고령층이 접근하기 쉬운 형태로 정보를 전달하는 스마트 홈 시스템입니다.

---

# 🧩 Branch 구성
1. Hermes_Android_App
   - 알림을 필터링하고 월패드로 전송하는 앱입니다.
2. Speaker
   - 알림을 송출하는 스피커를 구동시킵니다.
3. Vision-yolov8
   - 사용자의 얼굴을 인식하고 자세를 판단하여 알림을 수신하기에 적합한 상태인지 판단합니다.
4. Wallpad_BE
   - 월패드 서버와 백엔드 코드입니다.
5. Wallpad_FE
   - 월패드 프론트엔드 코드입니다.
